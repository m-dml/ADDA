State¶

class adda.system.state.State(x: torch.Tensor | tensordict.TensorDict, time_axis: torch.Tensor = None)[source]¶

Object representing a system state (trajectory).

Its fields are a Tensordict with two shared (batch) dimensions: the batch dimension, followed by the time dimension. It also contains a time axis.
