MaskedIidGaussianTimeInterpolatedObsOp¶

class adda.observation.operators.MaskedIidGaussianTimeInterpolatedObsOp(mask: State, sigma: State, sample_points: bool = False)[source]¶

Masked Identity Gaussian observation operator. It is assumed that the first input of the log-prob always has a regular time axis. The log-prob and conditional mean are computed by linearly interpolating the state variable to the observation time axis.

Parameters:

  • mask (State) – mask fields per each variable

  • sigma (State) – variance per each variable. Should have the same time and spatial dimensions as mask.

  • sample_points (bool) – if true, uses a sparse data structure to sample observation data

conditional_mean(x: State, first_time_ind: int = 0, last_time_ind: int = -1)[source]¶

Returns the conditional mean of the observations given a state x.

It can also be understood as directly applying the observation operator with no observation noise. Here, it is assumed that x covers the desired range of the observation time axis. :param x: current state :type x: State :param first_time_ind: first time index of the range of mask time axis on which the state is defined. :type first_time_ind: int :param last_time_ind: last time index of the range of mask time axis on which the state is defined. :type last_time_ind: int
