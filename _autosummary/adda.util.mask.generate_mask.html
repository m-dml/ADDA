generate_mask¶

adda.util.mask.generate_mask(shape: torch.Size | List | Tuple, p_obs: float, constant_obs_count_per_step: bool = True, constant_obs_count: bool = True) → tensordict.TensorDict | torch.Tensor[source]¶

Generates a mask for a State object with batch and time axes shared across all fields.

Parameters:

  • shape – the shape of the mask

  • p_obs – the proportion of observed variables across the trajectory.

  • mask. (If p_obs is a boolean tensor than it is directly used as the)

  • contant_obs_count_per_step – if this is true, enforces that the number of observed variables remains the same for each time step. Assumes first axis is time.

  • constant_obs_count – if this is true, the total number of observed variables is calculated deterministically. It can still vary for each time step. Applied only if constant_obs_per_step is False.
