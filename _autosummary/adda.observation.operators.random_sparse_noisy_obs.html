random_sparse_noisy_obs¶

adda.observation.operators.random_sparse_noisy_obs(x: State | torch.Tensor, obs_noise_sd: State | torch.Tensor | float | int | Dict, p_obs: torch.Tensor | float | Dict, time_axis=None, constant_obs_count_per_step: bool = True, constant_obs_count: bool = True) → Tuple[source]¶

Generate sparse and noisy observations from system state sequence.

Parameters:

  • x (Union[State, Tensor]) – a complete state sequence

  • obs_noise_sd (Union[State, Tensor, float, int, Dict]) – standard deviation of the observation noise

  • p_obs (Union[float, Dict]) – proportion of observed variables

:param : if provided, it is used instead of p_obs to define the mask. :param time_axis: time axis associated to the state sequence. Defaults to None. :type time_axis: _type_, optional :param contant_obs_count_per_step: if this is true, enforces that the number of observed variables remains the same

for each time step. Assumes first axis is time. Defaults to True.

Parameters:

constant_obs_count – if this is true, the total number of observed variables is calculated deterministically. It can still vary for each time step. Applied only if constant_obs_per_step is False. Defaults to True.

Returns:

input state sequence, converted to State class obs_op: observation operator obs: observations

Return type:

x
