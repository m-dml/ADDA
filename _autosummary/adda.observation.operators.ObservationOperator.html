conditional_mean(x: State, first_time_ind: int = 0, last_time_ind: int = -1)[source]¶

Returns the conditional mean of the observations given a state x. It can also be understood as directly applying the observation operator with no observation noise. If x does not cover the entire range of observations, we assume that it corresponds to a slice of the observation time axis, which must be specified using arguments first_time_ind and last_time_ind. These two arguments might remain unused for observation operator subclasses that have no time axis.

Parameters:

  • x (State) – current state

  • first_time_ind (int) – first time index of the range of observation time axis on which the state is defined.

  • last_time_ind (int) – last time index of the range of observation time axis on which the state is defined.

Returns (yhat): TensorDict
