impose_batch_sizes¶

adda.probability.distributions.impose_batch_sizes(distrib: Distribution, size: torch.Size, attrs: List) → Distribution[source]¶

Assign a batch size to TensorDict attributes of an input Distribution object. Throw an error if one TensorDict has more dimensions than the desired batch_size.

Parameters:

  • distrib (Distribution) – input

  • size (torch.Size) – desired batch_size

  • attrs (List) – list of names for the attributes on which to impose the batch sizes.

Returns:

updated input

Return type:

Distribution
