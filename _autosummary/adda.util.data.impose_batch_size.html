impose_batch_size¶

adda.util.data.impose_batch_size(x: tensordict.TensorDict, size: torch.Size) → tensordict.TensorDict[source]¶

Assign a batch_size to a TensorDict. Throw an error if the TensorDict has more dimensions than the desired batch_size.

Parameters:

  • x (TensorDict) – input

  • size (torch.Size) – desired batch_size

Returns:

updated input
