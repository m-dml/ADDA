LinearGaussianObsOp¶

class adda.observation.operators.LinearGaussianObsOp(H: State, P_chol: State = None)[source]¶

Linear Gaussian observation operator.

The operator defines a time-invariant linear mapping from states to observations. Observations must have a single field and a single dimension.

conditional_mean(x: State, first_time_ind: int = 0, last_time_ind: int = None)[source]¶

Returns the conditional mean of the observations given a state x. It can also be understood as directly applying the observation operator with no observation noise. If x does not cover the entire range of observations, we assume that it corresponds to a slice of the observation time axis, which must be specified using arguments first_time_ind and last_time_ind.

Parameters:

  • x (State) – current state

  • first_time_ind (int) – ignored for this observation operator class.

  • last_time_ind (int) – ignored for this observation operator class.
