sorted_index_range¶

adda.util.index.sorted_index_range(sorted_1Darray: torch.Tensor, min_val, max_val, nonempty: bool = False)[source]¶

Find indices into sorted array that fall into a chosen interval.

Parameters:

  • sorted_1Darray (Tensor) – sorted 1D Tensor

  • min_val (_type_) – left boundary of interval

  • max_val (_type_) – right boundary of interval

  • nonempty (bool, optional) – Throws an error if not indices are found. Defaults to False.

Returns:

maximum index such that sorted_1Darray[idx_start] <= min_val, or else len(sorted_1darray) idx_end: maximum index such that sorted_1Darray[idx_end] <= max_val, or else len(sorted_1darray)

Return type:

idx_start
