rollout¶

adda.util.state_space.rollout(m_dyn: Callable, output_times: torch.Tensor, x0: State, dynamic_inputs: State = None, static_inputs: State = None, store_every=None) → State[source]¶

Rollout a time-stepping function over a set of times.

Parameters:

  • m_dyn (Callable) – time stepping function with inputs x, dt, dynamic_inputs, static_inputs

  • x0 (State) – initial state, a tensor or tensordict, with a batch dimension

  • output_times (torch.Tensor) – times relative to initialization to produce output. must be increasing. optionally includes 0.

  • dynamic_inputs (State) – extra inputs (e.g. BCs, forcing) for each instance of calling the time stepping function.

  • static_inputs (State) – extra inputs (e.g. bathymetry) for each instance of calling the time stepping function.

  • store_every (int) – if specified, indicates at which frequency the states should be stored during the rollout

Returns:

states at each output time. First dimension is batch, second is time.

Return type:

x (State)
