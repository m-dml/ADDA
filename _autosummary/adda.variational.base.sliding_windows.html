sliding_windows¶

adda.variational.base.sliding_windows(state_time_axis: torch.Tensor, window_duration: float | int, window_shift: float | int = None, discard_partial: bool = False) → Tuple[source]¶

Get time windows for sliding window data assimilation.

Parameters:

  • state_time_axis (Tensor) – 1D tensor containing times for the state

  • window_duration (Union[float, int]) – length of assimilation window in time units (float) or time steps (int)

  • window_shift (Union[float, int], optional) – shift between consecutive windows, as a fraction of window size (float) or as a number of time steps (int). Defaults to 0.25.

  • discard_partial (bool, optional) – Discard windows extending beyond final observation, defaults False.
